# 🌿 Vitalis — Modern Nature & Glassmorphism Health Ecosystem

> A modern, responsive, and holistic Health & Vitality Tracking Web App built with React 19, Vite, Tailwind CSS, Recharts, and Web Audio API.

---

## ✨ Features

### 1. 📊 Interactive Dashboard & Analytics
- **Biometric Summary**: Real-time KPI highlights for Water, Steps, Weight, and Calories.
- **Toggleable Charts**: 7-Day Trend vs. 30-Day Trend views powered by **Recharts**.
- **Multi-Metric Switcher**: Toggle dynamically between Steps, Weight, and Calorie historical curves.

### 2. 📱 Core Daily Tracking Cards (10 Interactive Cards)
1. **💧 Water Intake**: 8 interactive glass cups, percentage progress indicator, and exact milliliter tracking (~2,000ml goal).
2. **👟 Steps Tracker**: 10,000 steps goal, 5 glowing green milestones (2k, 4k, 6k, 8k, 10k), slider & numeric input.
3. **⚖️ Weight Dynamics**: Daily weigh-in comparison with difference indicator (⬇ green for loss, ⬆ red for gain), kg/lbs toggle, and estimated BMI.
4. **❤️ Blood Pressure**: Systolic & Diastolic readings with automatic AHA classification (Normal, Elevated, High) and pulsing heart gauge.
5. **🏋️ Workout & Fitness**: Activity logger (HIIT, Running, Cycling, Strength, Yoga) with a built-in guided interval timer and audio cues.
6. **💊 Pills & Supplements**: Schedule morning/afternoon/evening vitamins with interactive checkboxes and compliance tracking.
7. **🌙 Sleep & Rest**: Bedtime/wake-up scheduler, sleep duration goal, and Deep/Light/REM sleep architecture breakdown.
8. **⏳ 16:8 Intermittent Fasting**: Live fasting timer with physiological stage indicators (Blood sugar drop, Fat burning, Ketosis, Autophagy).
9. **😊 Mind & Mood Wellness**: 5 mood states, 1-10 stress slider, mindful reflection diary, and a 1-minute guided breathing exercise.
10. **🥗 Diet & Calories**: Meal logging with category tags, timestamp, and a running total against daily calorie targets.

### 3. 🤖 "Dr. Vitalis" AI Health Chatbot
- Floating interactive clinical advisor widget.
- Context-aware analysis of your live daily biomarkers.
- Instant advice on nutrition, cardiovascular equilibrium, and restorative sleep in both **English and မြန်မာစာ (Burmese)**.

### 4. 🛡️ Admin Management Console
- Role-based authentication (Standard User vs. Administrator).
- User directory with health scores, biometric status, and permission controls.
- Global system health target baselines.

### 5. 📄 Certified Health Report (Print / PDF)
- One-click clinical-style summary report formatted for physician consultations.
- Built-in `window.print()` styling for instant PDF generation.

### 6. 🌲 Web Audio Nature Ambience Player
- 100% offline nature sound generator using the browser's Web Audio API.
- Switch between **Forest Breeze**, **Gentle Rain**, and **Ocean Waves**.
- Golden Tibetan singing bowl chime upon goal completion.

### 7. 🌐 Bilingual Localization & Theme Switcher
- Instant toggle between **English 🇬🇧** and **မြန်မာစာ 🇲🇲**.
- 5 Curated nature wallpapers (Misty Forest, Alpine Lake, Zen Stones, Deep Ocean, Golden Dawn).
- 6-Day Streak system with **Canvas Confetti** celebrations!

## 🛠️ Tech Stack

- **Framework**: React 19 (Vite)
- **Styling**: Tailwind CSS + Custom Frosted Glassmorphism
- **Icons**: Lucide React
- **Visualizations**: Recharts
- **Audio Engine**: Web Audio API (Synthesized Brown/Pink Noise)
- **Celebrations**: Canvas Confetti
- **State**: React State + Persistent LocalStorage

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Run

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/health-tracker.git

# 2. Navigate to the app directory
cd health/app

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
